# FitSystem

Projeto de estudo com a proposta de criar um sistema para academia, organizando informações de alunos, treinos e matrículas.

## Objetivo

Praticar o desenvolvimento de sistemas e a organização de um projeto usando Git e GitHub.

## Estado atual

O repositório contém esta apresentação inicial. As funcionalidades e instruções de execução serão atualizadas quando o código do sistema for adicionado.

## Ideias para evolução

- Cadastro e consulta de alunos.
- Organização de treinos e matrículas.
- Validação dos dados e documentação de uso.
